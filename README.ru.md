# Исследование китайской рукописи конца эпохи Цин (5 томов)

**О проекте**
Данный репозиторий содержит результаты текстологического, палеографического и кодикологического анализа пятитомной китайской рукописи, датированной 1721 годом (эпоха Канси). Сами сканы рукописи опубликованы на платформе Zenodo (ссылка в разделе «Источники»). Здесь представлены переводы, расшифровки, методология и Python-скрипты для работы с базой данных.

**Объект исследования**
Пятитомный сборник пророческих текстов, включающий:
*   Методологию расшифровки (Том 1).
*   «Песнь предвидения Неба и Земли» (乾坤預知歌).
*   «Песню о жареной лепёшке» (燒餅歌).
*   «Стихи чаньского наставника Хуанбо» (黃蘗禪師詩).
*   «Стелу Чжугэ Ляна» (孔明碑記).
*   «Сокровенную тайну Неба» (透天玄機).
*   Справочные таблицы («И цзин», 60-летний цикл, хронология).

**Ключевые результаты**
1.  **Палеографический анализ:** Выявлено минимум **4–5 переписчиков**, работавших в разное время (XVIII–XX вв.). Разный состав туши, почерки и наличие пустых листов подтверждают «живой» характер документа.
2.  **Датировка:** Финальная редакция выполнена **после 1905 года** (упоминание русско-японской войны и телеграфа).
3.  **Шарады:** Составлена карта из **39 разгаданных шарад** (23 — общеизвестные, 15 — расшифрованы нами). Три шарады остаются неразгаданными.
4.  **Скрипты:** В папке `/scripts/` представлены Python-скрипты (на русском языке) для пополнения базы данных.

**Структура репозитория**
*   `/docs/en/riddles_analysis.md` — разбор 5 шарад (на английском).
*   `/docs/ru/riddles_analysis.md` — разбор 5 шарад (на русском).
*   `/scripts/` — Python-скрипты (на русском языке).
